A static member is a variable that is tied to the class blueprint itself and not to any individual instance of an object. They are created before any instance of that class is ever created.
```C++
class Point {
public:
  // Constructors
  // Getters
  // Setters
private:
  double x_;
  double y_;
  // Since this is static, it is shared across all instances of  point
  static std::size_t count;
}
```

Normally you can't initialize a static variable in the class definition. If you mark it with the inline keyword, then you can do it that.
```C++
class Point {
public:
  // Constructors
  // Getters
  // Setters
private:
  double x_;
  double y_;
  // It is now initialized to 0 because it is marked as inline
  inline static std::size_t count{};
  // Can also make a static const type to save on memory on const data
  inline static const std::size_t pi{3.14};
}
```

## Static Member Functions
Just like a static member variable, this is a function that is tied to the blueprint of the class itself and not any one instance of the class. The following example has a static member function called printPointInfo.
```C++
class Point {
public:
	staic void printPointInfo(const Point& p) {
		std::cout << p.mX << p.mY << std::endl;
	}
}
```

Static member functions have one big downside, they don't have access to member variables of class objects. That is why in the example about, you had to pass throught the point explicitly.
