A namespace si a named scop that groups functions and types together so they don't clash with other objects with the same names.
```C++
namespace myNamespace {
	double mult(double x, double y) {
		return x * y;
	}
}

// To use that function
myNamespace::mult(x, y);
```

Namespaces can also be broken up across multiple files. This way you could define functions and classes in a namespace in a header file and implement them in a source file.
```C++
// file.h
namespace test {
	void yell();
}

// file.cpp
namespace test {
	void yell() {
		std::println("yeet!");
	}
}
```
