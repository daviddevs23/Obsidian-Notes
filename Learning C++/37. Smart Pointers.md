Unique pointers are wrappers around normal pointers that automatically free any memory that was manually allocated. This is a part of an effort for modern C++ to improve memory management. All smart pointers live in the memory header.

## Unique Pointers
A unique pointer is a smart pointer that makes it so that at any given moment, only be one pointer managing that location in memory. Just like normal smart pointers, the memory is automatically released when the pointer goes out of scope.
``` C++
// One way of initiliazing a unique pointer
std::unique_ptr<Dog> testDog1 {new Dog("Douge")};

// Can give it memory to manage later using std::move
std::unique_ptr<Dog> testDog2 {nullptr};

// The best way
std::unique_ptr<Dog> testDog3 = std::make_unique<Dog>("Douge");
```

You can also reset a smart pointer using the .reset() function on a smart pointer. This will release the memory for you and set the pointer to nullptr.

When passing a unique_ptr to a function, you will get an error unless you make it a const reference. When you make it a const reference, you are making the pointer a const reference, not the actual object. That means you can modify the object, but no the pointer.
```C++
void doSomething(const std::unique_ptr<Dog>& d) {
	d->setName("John");
	d->bark();
	// d.reset() // This will cause a compile error
}
```

## Shared Pointers
Shared pointers, as the name suggests, are pointers that share a location in memory. They all point to the same point in memory as well as keeping a reference count. The reference count tells you how many shared pointers are pointing to that piece of memory.
```C++
std::shared_ptr<int> ptr1 = std::make_shared<int>(7);
ptr1.use_count();   // 1 instance
std::shared_ptr<int> ptr2 = ptr1;
ptr2.use_count();   // 2 instances
ptr1.use_count();   // 2 instances
```

For a shared pointer, the reset() method will set that specify instance of a shared pointer to nullptr and decrement the reference count by 1. If the last shared_ptr is reset, then the memory will be freed.
