Overloading an operator allows us to define custom operator behavior for our own types.

## Addition Operator Overloading
Overloading the addition operator let's you define how two objects will be added together. Here is how you do it so it is a member function.
```C++
class Point {
  public:
	Point operator+(const Point& right)	const {
	  return Point(x_ + right.x_, y_ + right.y_);
	}
}
```

This is how you do it as a non member function and just overload the global addition operator.
```C++
Point operator+(const Point& left, const Point& right) {
  return Point(left.x_ + right.x_, left.y_ + right.y_);
}
```

## Overloading Subscript Operator
The subscript operator ([]) is what we use to index arrays. This one must be set up as a member function.
```C++
class Point {
  public:
	double operator[](size_t index){
	  assert((index == 0) || (index == 1));
	  return (index == 0) ? x_ : y_;
	}
}
```

That example only allows you to read data, this is how you overload the subscript operator to allow updating data. All it does is return a reference to the object.
```C++
class Point {
  public:
	double& operator[](size_t index){
	  assert((index == 0) || (index == 1));
	  return (index == 0) ? x_ : y_;
	}
}
```

## Setting Up Cast Conversions
You can set up custom cast conversions for your type. Here is an example of one that casts your point into a double as a member function.
```C++
explicit operator double() const {
	return static_cast<double>(x_ + y_);
}
```

## Copy Assignment Operator
This allows you to define custom behavior for the copy operator. Now, your custom classes and objects will be able to control the way they are copied. If you don't specify one, the compiler will implement a member wise copy for you. This can also only be done as a member function.
```C++
Point& operator=(const Point& rightOperand) {
	if (this != &rightOperand) {
		x_ = rightOperand.x_;
		y_ = rightOperand.y_;
	}
	return *this;
}
```

## Functors
A functor is when a function is called with (). You can override this to define custom behavior when you call className(). The following is an example as a member wise function.
```C++
// you can have whatever parameters and overloads
void operator()(std::string name) {
	std::cout << "Hello there: " << name << std::endl;
}
```
