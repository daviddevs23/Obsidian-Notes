Overloading an operator allows us to define custom operator behavior for our own types.

## Addition Operator Overloading
Overloading the addition operator let's you define how two objects will be added together. Here is how you do it so it is a member function.
```C++
class Point {
  public:
	Point operator+(const Point& right)	const {
	  return Point(x_ + right.x_, y_ + right.y_);
	}
}
```

This is how you do it as a non member function and just overload the global addition operator.
```C++
Point operator+(const Point& left, const Point& right) {
  return Point(left.x_ + right.x_, left.y_ + right.y_);
}
```

## Overloading Subscript Operator
The subscript operator ([]) is what we use to index arrays. This one must be set up as a member function.
```C++
class Point {
  public:
	double operator[](size_t index){
	  assert((index == 0) || (index == 1));
	  return (index == 0) ? x_ : y_;
	}
}
```

That example only allows you to read data, this is how you overload the subscript operator to allow updating data. All it does is return a reference to the object.
```C++
class Point {
  public:
	double& operator[](size_t index){
	  assert((index == 0) || (index == 1));
	  return (index == 0) ? x_ : y_;
	}
}
```
