There are 7 logical operators, they are as follows.

| ==  | equal                 |
| --- | --------------------- |
| !=  | not equal             |
| <   | less than             |
| >   | greater than          |
| <=  | less than or equal    |
| >=  | greater than or equal |
| <=> | three-way comparison  |
This is how you implement it as a member function.
```C++
bool operator>(const Point& other) const;
bool operator<(const Point& other) const;
bool operator>=(const Point& other) const;
bool operator<=(const Point& other) const;
bool operator==(const Point& other) const;
bool operator!=(const Point& other) const;
```

## Three way Comparison Operator
The three way comparison operator (<=>) does not return an int when it is used, it instead returns a type who's value is comparible to literal 0. So if the value you get back is equivelant to 0, they are equal. If it is greater, then the left hand is greater than or equal to the right hand side and the opposite is true when it is less than 0. The return type can be one of the following three.
- std::strong_ordering
- std::weak_ordering
- std::partial_ordering

## Strong Ordering
A type that can be used to describe absolute equality in comparisons. An example of a type that can have absolute equality is an int. This is because if you compare two ints of the same value, you can't distiguish between them. They are both exactly the same.

## Weak Ordering
A type that can be used to describe non absolute equality in comparisons. An example of a type that has non absoulte equality are strings. "HELLO" and "hello" may be considered equivelant but not equal.

## Partial Ordering
A type that can be used to describe incomparible values for a certain type. This means that comparing to values might be not equal, not less, and not greater all at the same time. An example would be comparing a double and NaN.

## Default Equality
By default, the default implementation of the equality operator does a member wise comparison. It will go through each member variable and check to see if they are all equivelant.
